# 本地数据目录

原始数据和派生数据不纳入 Git 仓库。请在本地按项目脚本预期放置：

- `data/THUCNews/<类别>/*.txt`：THUCNews 14 类原始语料。
- `data/199801/199801.txt` 至 `data/199801/199806.txt`：人民日报 1998 年 1–6 月原始语料。
- `data/interim/`：清洗后的中间文件，由数据处理脚本生成。
- `data/processed/`：U/L 划分、词向量输入和索引等派生产物，由项目脚本生成。

原始语料、标注文件及其授权条款应从课程/数据提供方获取并遵守相应使用限制；不要将原始数据或凭据提交到公开仓库。
